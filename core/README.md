## 🧪 Convenciones / Conventions

**ES:** Los scripts independientes se ejecutan con `zig run` o se compilan con `zig build-exe`. Los proyectos tipo librería separan `src/` y `test/`, usan `build.zig` y prueban con `std.testing` mediante `zig build test --summary all`.

**EN:** Standalone scripts run with `zig run` or compile with `zig build-exe`. Library-style projects separate `src/` and `test/`, use `build.zig`, and test with `std.testing` through `zig build test --summary all`.
