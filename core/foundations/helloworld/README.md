## 📄 Archivos de configuración clave / Key Configuration Files

No se requieren archivos de configuración para este ejercicio.

```zig
const std = @import("std");
const Io = std.Io;

pub fn main(init: std.process.Init) !void {
    const io = init.io;
    var stdout_buffer: [0x100]u8 = undefined;
    var stdout_writer = Io.File.stdout().writer(io, &stdout_buffer);
    const stdout = &stdout_writer.interface;
    try stdout.print("Hello, World! from Zig!\n", .{});
    try stdout.flush();
}
```

| Elemento | Propósito |
|----------|-----------|
| `@import("std")` | Importa la biblioteca estándar de Zig. |
| `pub fn main(init: std.process.Init) !void` | Define el punto de entrada del ejecutable; recibe el contexto del proceso, con su `Io`. |
| `Io.File.stdout().writer(io, &buffer)` | Abre un escritor con búfer sobre la salida estándar. |
| `stdout.print(...)` | Escribe el texto formateado en **stdout**. |
| `stdout.flush()` | Vacía el búfer para que el texto salga antes de terminar. |

## 🚀 Compilación y ejecución / Build & Run

### Requisitos / Requirements

- **Zig 0.17.0**.
- El ejecutable `zig` disponible en el `PATH`.

Verificar la instalación:

```bash
zig version
```

Salida verificada:

```text
0.17.0
```

### Ejecutar directamente / Run directly

```bash
cd zig/core/foundations/helloworld
zig run hello_world.zig
```

### Compilar y ejecutar / Compile and run

```bash
cd zig/core/foundations/helloworld
zig build-exe hello_world.zig -femit-bin=/tmp/zig-hello-world
/tmp/zig-hello-world
```

### Salida esperada / Expected output

```text
Hello, World! from Zig!
```

La salida fue verificada ejecutando el archivo con `zig run` y ejecutando el binario generado con Zig 0.17.0 en Linux/WSL2.

The output was verified by running the file with `zig run` and running the binary generated by Zig 0.17.0 on Linux/WSL2.

## 📝 Notas de implementación / Implementation Notes

- **ES:** Zig requiere una función `main` como punto de entrada del ejecutable.
- **EN:** Zig requires a `main` function as the executable entry point.

- **EN:** `std.debug.print` writes to **stderr**; for standard output a writer over `Io.File.stdout()` is used.
- **ES:** El ejecutable generado en `/tmp` es un artefacto de compilación y no forma parte del código fuente del ejercicio.
- **EN:** The executable generated under `/tmp` is a build artifact and is not part of the exercise source code.
