## 🛠️ Enfoque y construcción / Approach & Build

**ES:** El proyecto se creó manualmente, sin `build.zig` ni herramientas de scaffolding. Un único archivo `.zig` es suficiente: Zig puede ejecutar el archivo directamente o compilarlo a un ejecutable nativo.

**EN:** The project was created manually, without `build.zig` or scaffolding tools. A single `.zig` file is enough: Zig can run the file directly or compile it into a native executable.

### Inicialización / Initialization

1. Crear la estructura de directorios:

   ```bash
   mkdir -p zig/core/foundations/helloworld
   ```

2. Escribir el archivo `hello_world.zig` con el código fuente.

3. Ejecutarlo con `zig run` o compilarlo con `zig build-exe`.

---

## 📄 Archivos de configuración clave / Key Configuration Files

No se requieren archivos de configuración para este ejercicio.

```zig
const std = @import("std");

pub fn main() void {
    std.debug.print("Hello, world! from Zig\n", .{});
}
```

| Elemento | Propósito |
|----------|-----------|
| `@import("std")` | Importa la biblioteca estándar de Zig. |
| `pub fn main() void` | Define el punto de entrada del ejecutable. |
| `std.debug.print(...)` | Imprime texto formateado en la salida estándar. |
| `.{}` | Proporciona una lista vacía de argumentos de formato. |

## 🚀 Compilación y ejecución / Build & Run

### Requisitos / Requirements

- **Zig 0.16.0**.
- El ejecutable `zig` disponible en el `PATH`.

Verificar la instalación:

```bash
zig version
```

Salida verificada:

```text
0.16.0
```

### Ejecutar directamente / Run directly

```bash
cd zig/core/foundations/helloworld
zig run hello_world.zig
```

### Compilar y ejecutar / Compile and run

```bash
cd zig/core/foundations/helloworld
zig build-exe hello_world.zig -femit-bin=/tmp/zig-hello-world
/tmp/zig-hello-world
```

### Salida esperada / Expected output

```text
Hello, world! from Zig
```

La salida fue verificada ejecutando el archivo con `zig run` y ejecutando el binario generado con Zig 0.16.0 en Linux/WSL2.

The output was verified by running the file with `zig run` and running the binary generated by Zig 0.16.0 on Linux/WSL2.

## 📝 Notas de implementación / Implementation Notes

- **ES:** Zig requiere una función `main` como punto de entrada del ejecutable.
- **EN:** Zig requires a `main` function as the executable entry point.
- **ES:** `std.debug.print` usa una plantilla de formato y una tupla de argumentos; en este ejemplo la tupla está vacía.
- **EN:** `std.debug.print` uses a format template and an argument tuple; this example uses an empty tuple.
- **ES:** El ejecutable generado en `/tmp` es un artefacto de compilación y no forma parte del código fuente del ejercicio.
- **EN:** The executable generated under `/tmp` is a build artifact and is not part of the exercise source code.
